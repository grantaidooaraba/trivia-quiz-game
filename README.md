# Trivia Quiz Game
A relaxed, responsive quiz with eight locally stored questions, one point per correct answer, answer feedback, and a restartable results screen.

## Run locally
Requires Node.js 20.19+ or 22.12+. Run `npm install`, `npm run dev`; use `npm run build` for production.

## Features
- Eight questions across several subjects, one at a time.
- Single answer per question, clear answer feedback, live score and progress.
- Final score summary and working restart.

## Data and limitations
Questions are curated and stored locally, so the experience does not depend on a trivia API or network access.
